# Lanternbit Labs website

Free hosting on GitHub Pages. Upload everything in this folder to a public repository named `USERNAME.github.io`; then:

| Page | Address |
|---|---|
| Studio home | `https://USERNAME.github.io/` |
| Fair Square privacy policy (Play Console, AdMob consent message) | `https://USERNAME.github.io/fair-square/privacy.html` |
| app-ads.txt (AdMob) | `https://USERNAME.github.io/app-ads.txt` |

Contact email used on every page: lanternbit.labs@gmail.com.
For each new game, add a folder like `fair-square/` with its own `privacy.html` and a card on `index.html`. One `app-ads.txt` covers every game.
